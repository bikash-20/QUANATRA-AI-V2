# Geometry

- Circle: A = pi r^2, C = 2 pi r. Chord at distance d from center: half-chord = sqrt(r^2 - d^2).
- Right triangles: a^2 + b^2 = c^2. Common triples: 3-4-5, 5-12-13, 8-15-17, 7-24-25.
- Equilateral triangle: area = (sqrt3 / 4) s^2. 30-60-90 sides: 1 : sqrt3 : 2.
- Distance: sqrt((x2-x1)^2 + (y2-y1)^2).
