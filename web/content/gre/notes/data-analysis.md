# Data Analysis, Probability & Counting

- Median of an even-sized set = mean of the two middle values (sort first).
- Standard deviation measures spread around the mean; a more spread-out set has the larger SD.
- Permutations with repeats: n! / (a! b! ...). Combinations: C(n,k) = n! / (k!(n-k)!).
- 'At least one' = total - none.
